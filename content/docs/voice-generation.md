# Voice generation

Short, well-punctuated input usually produces the most consistent delivery. Use sentence boundaries to control pacing and keep numbers or abbreviations unambiguous.

## Production checklist

- Keep a stable voice id for each product surface.
- Choose one output format per delivery path.
- Log latency, request ids, and provider errors.
- Test names, numbers, and mixed-language phrases before launch.
