## Current engine

Miralas uses Chatterbox Multilingual with the approved `t3_mtl23ls_v2.safetensors` checkpoint. The [upstream implementation](https://github.com/resemble-ai/chatterbox/blob/master/src/chatterbox/mtl_tts.py) lists 23 supported languages; explore them in [language coverage](/#languages).

Model support describes the engine. It does not guarantee a published public voice per language or public Console access. Curated public voices have not been announced.

## Audio output

The engineering baseline validates 24 kHz mono PCM16 output. The model's [sample-rate constant](https://github.com/resemble-ai/chatterbox/blob/master/src/chatterbox/models/s3gen/const.py) is 24,000 Hz. Speech quality varies by language, text and reference recording.

## Access and limits

Public Console and API access, quotas and usage terms are not confirmed. Release-specific instructions will be published when access is announced. This page does not provide an unverified endpoint or rate limit.

## Uzbek Speech — In Development

We're working toward native Uzbek speech capabilities through research, data collection and model evaluation. Uzbek is not supported by the current multilingual checkpoint and is not available for production inference.

## Performance validation

Docker and CUDA benchmark preparation is complete. Real NVIDIA GPU benchmarks remain pending. Validated output formatting does not establish real-time synthesis, production speed or scalability.

Follow [development updates](/resources/changelog) for progress.
