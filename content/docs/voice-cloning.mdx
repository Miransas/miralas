## Overview

Voice cloning lets your product speak in a branded or personalized voice. It is useful for customer support, creators, sales flows, and any use case where a recognizable voice adds trust and clarity.

## Requirements

Before starting, make sure you have:

- A Miralas account with an active API key
- Clean audio samples with a clear voice
- Permission from the original speaker

## Sample guidance

Use recordings with minimal noise and consistent tone. A strong sample set is usually the biggest driver of quality.

```bash
npm install @miralas/sdk
```

## Upload samples

```javascript
import { MiralasClient } from '@miralas/sdk';
import fs from 'fs';

const miralas = new MiralasClient({
  apiKey: process.env.MIRALAS_API_KEY,
});

const sample = await miralas.voiceCloning.uploadSample({
  name: 'brand-voice-sample',
  audio: fs.readFileSync('./samples/clean_audio.wav'),
  format: 'wav',
});

console.log(sample.id);
```

## Train the model

```javascript
const model = await miralas.voiceCloning.train({
  name: 'Brand voice',
  sampleIds: [sample.id],
  description: 'Voice for onboarding and product support flows.',
});

console.log(model.id);
```

## Generate speech with the cloned voice

```javascript
const audio = await miralas.tts.generate({
  voiceId: model.voiceId,
  text: 'Welcome to Miralas. We build voice products for modern teams.',
  format: 'mp3',
  speed: 1.0,
});

console.log('speech generated');
```

## Best practices

- Use permissioned audio only.
- Keep recordings clean and consistent.
- Test multiple samples before finalizing the model.
- Use cloned voices in product flows that match the brand tone.


```bash
curl -X POST https://api.miralas.io/v1/tts/generate \
  -H "Authorization: Bearer $MIRALAS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "voiceId": "vc_a1b2c3d4e5f6",
    "text": "Hello, and welcome to the Miralas Voice AI platform.",
    "format": "mp3",
    "speed": 1.0
  }' \
  --output speech.mp3
```

## Best Practices

To get the most out of voice cloning, keep these principles in mind:

- **Use high-quality source audio** — garbage in, garbage out. The single biggest factor in clone quality is the input audio.
- **Test with varied text** — after training, generate speech with different sentence types (questions, commands, narrative) to evaluate quality.
- **Fine-tune with more data** — if the clone doesn't capture the speaker's range, upload additional samples and retrain.
- **Respect ethical guidelines** — only clone voices you have permission to use, and clearly label AI-generated audio where appropriate.
- **Monitor usage** — cloned voice generation counts toward your TTS quota. Use the dashboard to track usage and set limits.

If you encounter issues during cloning, check the [troubleshooting guide](https://miralas.io/docs/troubleshooting) or reach out on [Discord](https://discord.gg/miralas).
