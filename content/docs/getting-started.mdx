## Current status

Miralas is a voice platform by Miransas. This repository is the public marketing website and documentation, separate from the Miralas Console application and private inference services.

Public Console and API access are not confirmed. The [Console entry point](https://console.miralas.io) is an access destination, not a promise of public sign-up. Follow [development updates](/resources/changelog) for announcements.

## Engineering foundation

The supplied engineering baseline identifies Chatterbox Multilingual as the active text-to-speech engine, using `t3_mtl23ls_v2.safetensors`. The model supports 23 languages. See [language coverage](/#languages) and the [active model](/product/models).

A Rust API connects to a Python inference worker over gRPC. The validated output format is 24 kHz mono PCM16. Voice Catalog infrastructure is implemented; published curated voice seeds have not been verified.

## Uzbek Speech — In Development

We're working toward native Uzbek speech capabilities through research, data collection and model evaluation. Uzbek is not included in the current engine's 23 languages and is not available for production inference.

## What remains in development

- Public voice cloning workflows and an expanded curated voice catalog
- Public API access, endpoints, SDKs and billing terms
- Speech-to-speech and voice agents
- Real NVIDIA GPU benchmarks; Docker and CUDA preparation is complete

Qwen, CosyVoice and Miransas-native models are future research plans, not current integrations. No production latency or scalability numbers are published.
