## What is Miralas.io?

Miralas.io is an advanced Voice AI platform that enables developers to build, deploy, and scale voice-powered applications with minimal effort. Whether you're building a conversational AI assistant, a text-to-speech narration system, or a real-time voice transformation pipeline, Miralas.io provides the tools you need.

### Core Capabilities

The platform is built around four core pillars:

- **Voice Agents** — Deploy intelligent conversational agents that can make and receive phone calls, handle natural dialogue, and execute tasks autonomously.
- **Text-to-Speech (TTS)** — Convert written text into natural, human-sounding audio in over 30 languages and 200+ voices.
- **Speech-to-Speech (STS)** — Transform a speaker's voice in real time while preserving emotion, intonation, and cadence.
- **Voice Cloning** — Create a custom digital replica of any voice from a short audio sample.

## Installing the SDK

The Miralas Node.js SDK is available on npm and works with any JavaScript runtime that supports `fetch` (Node 18+).

```bash
npm install @miralas/sdk
```

Or using yarn:

```bash
yarn add @miralas/sdk
```

### Verifying the Installation

After installing, verify the SDK is properly imported:

```javascript
import { MiralasClient } from '@miralas/sdk';

const miralas = new MiralasClient({
  apiKey: process.env.MIRALAS_API_KEY,
});

console.log('Miralas SDK initialized successfully.');
```

## Authentication

All API requests require a valid API key. You can generate and manage your keys from the [Miralas Dashboard](https://dashboard.miralas.io/api-keys).

### Getting Your API Key

1. Navigate to [dashboard.miralas.io](https://dashboard.miralas.io)
2. Go to **Settings > API Keys**
3. Click **Create New Key**
4. Copy the key and store it securely — it will not be shown again

### Using Environment Variables

Never hardcode your API key in source files. Instead, use environment variables:

```bash
# .env
MIRALAS_API_KEY=mr_live_your_api_key_here
```

Then reference it in your code:

```javascript
import { MiralasClient } from '@miralas/sdk';

const miralas = new MiralasClient({
  apiKey: process.env.MIRALAS_API_KEY,
});
```

### API Key Security

Your API key grants full access to your Miralas account. Follow these best practices:

- **Never** commit your `.env` file to version control
- Rotate keys quarterly or after any suspected exposure
- Use separate keys for development and production environments
- Restrict key permissions to only the scopes your application needs

## Your First Voice Agent

Now that you're authenticated, let's create a simple voice agent that can answer phone calls and respond to callers.

### Creating an Agent

```javascript
import { MiralasClient } from '@miralas/sdk';

const miralas = new MiralasClient({
  apiKey: process.env.MIRALAS_API_KEY,
});

const agent = await miralas.agents.create({
  name: 'Customer Support Agent',
  voice: 'aria',
  systemPrompt: 'You are a helpful customer support assistant for Acme Corp. Be concise and friendly.',
  phoneNumbers: ['+15551234567'],
});

console.log(`Agent created with ID: ${agent.id}`);
```

### Configuring the Agent's Voice

Miralas offers a library of pre-built voices. You can browse them in the dashboard or list them programmatically:

```javascript
const voices = await miralas.voices.list();

voices.forEach((voice) => {
  console.log(`${voice.id} — ${voice.name} (${voice.language})`);
});
```

### Testing Your Agent

Once your agent is created and a phone number is assigned, you can test it by calling the number. You can also simulate a call in the dashboard's **Playground** tab.
