## Overview

Miralas helps teams build voice-first products with a reliable API layer for agents, speech generation, real-time audio processing, and custom voice experiences.

The platform is organized around four core capabilities:

- **Voice agents** for conversational workflows and live calling
- **Text-to-speech** for natural audio generation from text
- **Speech-to-speech** for real-time voice transformation
- **Voice cloning** for branded or personalized voice experiences

## Install the SDK

The Node.js SDK is the fastest way to begin. It works with modern JavaScript runtimes and supports the standard auth pattern used across the platform.

```bash
npm install @miralas/sdk
```

If your team uses Yarn:

```bash
yarn add @miralas/sdk
```

## Authentication

All API requests require a valid API key. Create and manage keys from the Miralas dashboard.

```bash
# .env
MIRALAS_API_KEY=your_key_here
```

Then initialize the client:

```javascript
import { MiralasClient } from '@miralas/sdk';

const miralas = new MiralasClient({
  apiKey: process.env.MIRALAS_API_KEY,
});
```

## Create your first voice agent

```javascript
import { MiralasClient } from '@miralas/sdk';

const miralas = new MiralasClient({
  apiKey: process.env.MIRALAS_API_KEY,
});

const agent = await miralas.agents.create({
  name: 'Customer support agent',
  voice: 'aria',
  systemPrompt: 'You are a helpful support assistant. Keep responses brief and professional.',
});

console.log(agent.id);
```

## Recommended workflow

1. Create the agent.
2. Configure the voice and instructions.
3. Connect your backend tools or business workflows.
4. Test with a real call or simulation.
5. Ship with monitoring and analytics.

## Best practices

- Keep prompts concise and explicit.
- Keep secrets in environment variables.
- Use separate keys for dev and production.
- Validate production flows with real-world call scenarios.
