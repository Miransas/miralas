## About Miralas

Miralas is a voice platform by Miransas. Its current speech foundation is Chatterbox Multilingual, with a Rust API and Python inference worker connected through gRPC.

We are building toward useful voice tools for creators, product teams and developers. Public Console and API access are not confirmed; voice cloning workflows, speech-to-speech and voice agents remain in development.

### Uzbek Speech — In Development

We're working toward native Uzbek speech capabilities through research, data collection and model evaluation. Uzbek remains an important research direction, separate from the active engine's 23 supported languages. It is not available for production inference.

### What guides the work

- **Permission.** Use voice recordings only when you own them or are authorized to use them.
- **Clarity.** Distinguish model capabilities, validated engineering, development work and future research.
- **Evaluation.** Publish performance claims only when measurements support them. Real NVIDIA GPU benchmarks remain pending.
