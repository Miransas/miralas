# Security Policy

## Supported Versions

We actively issue security updates for the following versions of our projects:

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The **Miransas** team takes software security seriously. If you discover a vulnerability or security issue in any of our repositories, please do NOT create a public GitHub Issue.

### How to Report

1. **Email:** Send a detailed security report to **contact@miransas.com** (or use GitHub Private Vulnerability Reporting directly on the repository).
2. **Details to Include:**
   - Type of vulnerability / attack vector
   - Steps to reproduce the issue
   - Proof-of-concept (PoC) code or screenshots if available
   - Impact assessment

### Our Commitment

- We will acknowledge receipt of your report within **48 hours**.
- We will work on a resolution and keep you informed of our progress.
- Once fixed, we will publish a patch release and credit your responsible disclosure (if desired).

Thank you for helping keep Miransas tools and ecosystem secure!
